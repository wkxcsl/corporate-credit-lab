# 独立手算验算例

单位：百万元。输入收入1000、成本600、EBIT 200、净利润120、折旧摊销20、现金100（受限10）、应收200、存货120、应付60、短债100、长债200、现金利息20、CFO 160、维持性开支30、到期本金80。

压力情景：收入下降10%、毛利率下降2个百分点、应收额外30天、存货额外10天、应付额外5天、利率上升200基点、50%债务重定价、现金税率近似25%。

| 手算步骤 | 结果 |
|---|---:|
| 收入1000×90% | 900 |
| 毛利率40%−2个百分点 | 38% |
| 毛利900×38% | 342 |
| 毛利变化342−400 | −58 |
| EBIT 200−58 | 142 |
| 利息20+300×50%×2% | 23 |
| 税款变化(119−180)×25% | −15.25 |
| 应收900×(0.2+30/365) | 253.972603 |
| 存货558×(0.2+10/365) | 126.887671 |
| 应付558×(0.1+5/365) | 63.443836 |
| 营运资金增加 | 57.416438 |
| CFO 160−58+15.25−57.416438 | 59.833562 |
| 可偿债现金流CFO−30 | 29.833562 |
| 本息23+80 | 103 |
| 覆盖倍数29.833562/103 | 0.289646 |
| 偿债后现金90+29.833562−103 | 16.833562 |
| 未融资缺口 | 0 |

这个例子说明：当期经营产生的可偿债现金不足本息（覆盖倍数<1），但期初现金仍可弥补，因此不一定出现年度末资金缺口。不能把两个概念混为一谈。
