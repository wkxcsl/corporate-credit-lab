### 分析口径与边界

本项目用于理解非金融企业的财务与现金偿债能力，不代表任何银行内部模型。输入为同一会计口径的完整年度数据，金额统一为人民币百万元；不支持把季报直接当年报、跨币种汇总或直接分析银行/保险公司的报表。

#### 财务指标

| 指标 | 公式 / 说明 |
|---|---|
| 毛利率 | (收入−营业成本)/收入 |
| 净利率 | 净利润/收入 |
| 资产负债率 | 总负债/总资产，负债不等于有息债务 |
| 流动比率 | 流动资产/流动负债 |
| 现金短债比 | (货币资金−受限资金)/短期有息债务 |
| 现金利息保障 | EBIT/现金利息支出；并非按利润表利息费用计算的标准TIE |
| 现金利润比 | CFO/净利润；净利润≤0时无意义，显示N/A |
| EBITDA近似 | EBIT+折旧摊销；不等于经审计或调整后EBITDA |
| 净债务/EBITDA近似 | (短期债务+长期债务−非受限现金)/(EBIT+折旧摊销)；EBITDA≤0时N/A，净现金企业可为负 |
| DSO | 应收账款平均余额/收入×365；收入代替赊销额 |
| DIO | 存货平均余额/营业成本×365 |
| DPO | 应付账款平均余额/营业成本×365；成本代替采购额 |
| CCC | DSO+DIO−DPO |
| 现金偿债覆盖近似 | (CFO−维持性资本开支)/(现金利息+未来12个月到期本金) |

连续上年存在时用期初期末平均余额；缺少连续上年时用期末余额近似并提示。分母≤0统一显示N/A，不填0、不把无债企业当作覆盖不足；分子为负时保留负数。

#### 一年期压力测试

这是透明的增量现金桥接，**不是完整的三表预测**。金额为百万元，百分比参数按小数传入；毛利率变化为百分点，利率变化为基点。

1. 情景收入 = 基准收入 × (1−收入下降比例)。
2. 情景毛利率 = 基准毛利率−毛利率下降百分点/100；情景成本 = 情景收入×(1−情景毛利率)。毛利允许为负。
3. 期间经营费用保持不变，情景EBIT = 基准EBIT+毛利变化。
4. 情景利息 = 基准现金利息+存量有息债务×重定价比例×上升基点/10000；近似假设相关余额全年存在，不模拟逐笔摊还。
5. 税款变化 = [max(情景EBIT−情景利息,0)−max(基准EBIT−基准利息,0)]×假设现金税率。只计算税差，不预测退税、亏损结转和递延税。
6. 应收 = 情景收入×(基准期末应收/基准收入+额外DSO/365)。存货及应付同理，以情景成本为分母基准并分别加DIO、DPO冲击。
7. 营运资金增加 = 情景(应收+存货−应付)−基准期末(应收+存货−应付)。
8. 情景CFO = 基准CFO+毛利变化−税款变化−营运资金增加。
9. 可偿债现金流 = 情景CFO−维持性资本开支；本息支出 = 情景现金利息+未来12个月到期本金。
10. 偿债后现金 = 基准非受限现金+可偿债现金流−本息支出；未融资缺口=max(0,−偿债后现金)。

历史周转分析用平均余额，情景校准用期末余额。两者目的不同：后者保证所有冲击为0时精确回到基准，避免无冲击就产生人为营运资金释放。

**现金流分类前提**：输入CFO应尚未扣除筹资性现金利息。原报表若将已付利息列在经营活动，须把该部分加回后再输入；不能重复扣利息。现金利息支出也不等于利润表利息费用，税差使用它只是简化。

#### 尽调提示规则

70%资产负债率、0.8现金利润比、2倍现金利息保障是**手工设定的教学阈值**，没有行业校准、违约标签训练或回测。覆盖倍数1来自“现金流恰好覆盖本息”的算术边界。规则只生成尽调问题，不生成评分、PD、评级、批准/拒绝建议或可贷额度。

#### 已知局限

- 不考虑新增融资、自动续贷、注资、分红、扩张资本开支及担保履约；缺口不是授信额度。
- 不扣最低经营现金储备，可能低估真实资金需求；非受限现金也未必全部可用于还款。
- 未纳入票据、合同资产等其他经营性资产负债的变化；这些项目在情景中保持不变。
- 年度口径不能发现月内、季内到期错配；需补充月度滚动现金预算。
- 期间费用固定、全部收入按应收周转建模、成本按应付周转建模，均是近似。
- 数据通过恒等式和范围检查，不等于真实、准确或经过审计；来源字段由用户声明。
- 不支持金融企业、收入或成本为0的企业及多币种集团的直接混合分析。

#### 学习参考

- IFRS Foundation：[IAS 7 Statement of Cash Flows](https://www.ifrs.org/issued-standards/list-of-standards/ias-7-statement-of-cash-flows/)，理解经营、投资及筹资现金流分类；实际导入应以所用准则和报表附注为准。
- OpenStax：[Principles of Finance](https://openstax.org/details/books/principles-finance)，财务比率、营运资金与现金转换周期基础。

参考资料用于概念学习；本项目阈值和具体压力公式不是从银行制度或监管评级办法取得。合成数据生成规则在scripts/generate_demo.py，没有真实企业或银行客户数据。
