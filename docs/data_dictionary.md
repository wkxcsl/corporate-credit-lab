# 数据字典与导入要求

CSV为UTF-8或UTF-8 BOM编码，每行一家企业的一个完整年度，字段必须与模板完全一致。金额全部为**人民币百万元**：1百万元=100万元。百分比、金额、币种和年度不能混用。

| 字段 | 含义及口径 |
|---|---|
| company | 企业名称，必填；不同企业不得同名 |
| industry | 行业，必填 |
| year | 完整会计年度，整数；不接受小数或季报 |
| revenue | 全年营业收入，>0 |
| cogs | 全年营业成本，>0，不含期间费用 |
| ebit | 全年息税前利润，可负；须明确调整口径 |
| net_profit | 同合并范围净利润，可负 |
| depreciation | 全年折旧及摊销，非负 |
| cash | 年末货币资金，含受限部分 |
| restricted_cash | 其中不可自由使用部分，非负且≤cash |
| receivables | 年末应收账款账面价值（净额），不含合同资产和应收票据 |
| inventory | 年末存货账面价值 |
| current_assets | 年末流动资产总额 |
| total_assets | 年末资产总额，>0 |
| payables | 年末应付账款，不含应付票据 |
| current_liabilities | 年末流动负债总额 |
| total_liabilities | 年末负债总额，含经营负债 |
| equity | 年末所有者权益，可负；资产≈负债+权益 |
| short_debt | 年末流动有息债务，含一年内到期的长期债务，不含经营应付 |
| long_debt | 年末非流动有息债务，不重复计入一年内到期部分 |
| interest | 全年现金利息支付（含相关资本化利息），用于偿债支出及利息保障近似；不是财务费用净额 |
| cfo | 全年经营现金流净额，可负；须未扣筹资性现金利息，否则先重分类 |
| maintenance_capex | 预计未来12个月维持性资本开支，非负；不能把未知填成0 |
| principal_due | 基准年末之后12个月需归还本金（人工补充），≤全部有息债务，不自动等同short_debt |
| source | 来源说明；真实公开数据请附年度报告链接、页码、审计/合并口径及调整记录 |

维持性资本开支和到期本金是基准日之后12个月的前瞻补充项，其余为基准年历史数或年末余额。本工具不自动把财报总购建支出当作维持性支出。

缺失值、NaN、Infinity、重复企业年度、不平衡报表、重复或多余列均报错。除明确允许的利润、现金流、权益外，不接受负数。采用净额列示且存在特殊会计项目时，应先在工具外完成口径映射。

## 导入流程

1. 下载data/demo_financials.csv，保留列名，删除演示行。
2. 对公开年报逐项摘录，统一单位、合并范围和年度。核对最新重述后的比较数据。
3. 补充未来12个月本金到期与维持性资本开支假设，并在source记明来源。
4. 用连续年度构建同比及平均余额，上传后检查数据表和提示。
5. 在报告中解释无法取得的数据。**不要用0代替未知数据。**

默认案例为规则生成的合成观察值，并非完整三表，不能据此检查每期现金余额与全部现金流的勾稽关系。项目未声称完成真实企业的实证验证。
